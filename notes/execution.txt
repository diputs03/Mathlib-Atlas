Notes on Executing the Scripts
==============================

Layout
------
Lean extraction scripts live in  script\lean\  (NOT directly under script\).
Python helpers live in            script\python\.
Generated data goes to            data\.
Never modify external\mathlib4 (read-only).

Cost
----
Scripts 00-07 `import Mathlib`, which loads the entire Mathlib environment and
takes a few minutes (plus memory on the order of ~3 GB). Once loaded, traversing
the ~777k constants is cheap; design every extractor to load Mathlib ONCE and do
all passes in that process, rather than relaunching Lean per task.

Running (Windows, no WSL)
------------------------
From the repository root:

    lake env lean script\lean\06_module_statistics.lean
    lake env lean script\lean\07_persistent_corpus.lean
    lake env lean script\lean\08_dependency_graph.lean
    lake env lean script\lean\09_expr_relations.lean
    lake env lean script\lean\10_typeclasses.lean
    lake env lean script\lean\11_namespaces.lean
    lake env lean script\lean\12_decl_links.lean

Operational caveats learned the hard way:
* The correct path is `script\lean\<file>.lean`. A stale command using
  `script\<file>.lean` fails with "no such file or directory (error code 4058)"
  because that path no longer exists after the scripts were reorganized.
* In a non-interactive/background shell, `~/.elan/bin` may be missing from
  PATH; prefix the command with
      $env:PATH = "C:\Users\diput\.elan\bin;" + $env:PATH
  (the elan `lake` shim needs to spawn its child `lean`).
* The editor runs its own `lake serve` / `lean --server` / `lean --worker`
  processes; do not mistake those for a command-line run, and do not kill them.
