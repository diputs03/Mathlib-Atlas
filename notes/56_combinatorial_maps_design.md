# 56 — Combinatorial maps (rotation systems) from permutations — design note

## 1. What this layer is

Scripts 51 (planar edge bounds), 53 (crossing lemma) and 54 (incidence /
Szemerédi–Trotter / unit distance) all take a *geometric* drawing as a hypothesis
(`PlaneData`, crossing counts, etc.). Script 55 characterized planar maps
*inductively* (`IsPlanarMap`) and proved `v + f = e + 2` for that class.

Script 56 supplies the purely **combinatorial** foundation that sits underneath
both: the **rotation-system / dart** model of an orientable map, expressed only
with finite permutations (no topology imported).

A combinatorial map on a finite type `α` of **darts** (half-edges) is:

* `edge τ : Perm α` — a fixed-point-free involution (`τ² = 1`, `τ x ≠ x`); each
  2-cycle is an edge;
* `vert σ : Perm α` — the vertex rotation; each cycle is a vertex;
* `face φ := τ * σ⁻¹` — the face permutation; each cycle is a face.

## 2. Orbit counts from `cycleType`

Mathlib has no `numCycles`. We define

```
orbits α p = Multiset.card p.cycleType + (Fintype.card α - p.cycleType.sum)
```

(nontrivial cycles plus fixed points, since `sum cycleType = #support`).
Proved:

* `orbits α 1 = Fintype.card α` (`orbits_one`);
* `orbits α (swap a b) = Fintype.card α - 1` for `a ≠ b` (`orbits_swap`, via
  `isCycle_swap`, `support_swap`, `cycleType = {2}`);
* `orbits α p ≤ Fintype.card α` (`orbits_le_card`).

Two small multiset lemmas are proved by `Multiset.induction_on` with the
inductive hypothesis stated as a function (the motive form this Lean version
requires): every entry `≥ 2 ⇒ 2·card ≤ sum`; every entry `= 2 ⇒ sum = 2·card`.

## 3. The two structural theorems

**Dart count.** Because `τ` is a fixed-point-free involution, every nontrivial
cycle has length exactly 2 (`cycle_length_two`, via
`dvd_of_mem_cycleType` + `orderOf τ ∣ 2`), its support is all of `α`
(`edge_support_univ`), hence

```
theorem two_edges_eq_card : 2 * E = Fintype.card α
```

(the number of darts is even and `E = #darts / 2`).

**Parity of the Euler characteristic.** The central result, with no topology
assumed:

```
theorem chi_even : Even ((V : ℤ) - E + F)
```

Proof idea. `sign φ = sign τ · sign σ` (because `φ = τ·σ⁻¹` and
`sign σ⁻¹ = sign σ`). Mathlib's `sign_of_cycleType` writes `sign p` as
`(-1)^(sum cycleType + card cycleType)`. We prove the exponent congruence

```
(sum cycleType p + card cycleType p) ≡ card α - orbits p  (mod 2)
```

(`sign_exponent_parity`; `s + c = (s - c) + 2c`). Thus the signs of σ and φ
give parities of `N - V` and `N - F`; the sign of τ, together with `2E = N`,
gives parity `E`. Equating the two sides of `sign φ = sign τ · sign σ` yields
`(N-F) ≡ E+(N-V) (mod 2)`, i.e. `V - E + F ≡ 0 (mod 2)`.

Consequently an integer genus is well-defined and satisfies the orientable
Euler relation:

```
noncomputable def genus : ℤ := (2 - χ) / 2
theorem chi_eq_two_minus_two_genus : χ = 2 - 2 * genus
```

This proves, algebraically, the part of the orientable classification that
holds for **every** map: the characteristic is `2 mod 2`, so a combinatorial
genus exists.

## 4. Genus-zero seeds

On `Fin 2`, with `s2 = swap 0 1`:

* `linkMap` (`edge = s2`, `vert = 1`): **V = 2, E = 1, F = 1, χ = 2** — the
  single edge joining two vertices (the sphere with two marked points);
* `loopMap` (`edge = s2`, `vert = s2`): **V = 1, E = 1, F = 2, χ = 2** — the
  single loop on one vertex.

All six orbit counts and both characteristics are proved concretely (using
`orbits_one` / `orbits_swap`, not `decide` on permutations). These are the two
genus-zero base cells from which the inductive planar class of script 55 grows.

## 5. Honest scope — what is deliberately NOT proved here

1. **Connectedness.** Nothing forces the subgroup generated by τ and σ to act
   transitively. For a disconnected map, `χ = 2 - 2g` still gives *an* integer
   `g`, but it is `2·(1 - g) = Σ components (2 - 2gᵢ)`, i.e. `g` is the
   reduced total genus, not the genus of one surface.
2. **`genus ≥ 0` (`χ ≤ 2`).** The non-negativity of the genus of a connected
   map is the topological half of the classification. Algebraically it needs
   the lemma that a transposition changes the number of cycles of a permutation
   by exactly ±1 (a swap **splits or joins** one cycle), which Mathlib does not
   provide ready-made. With that lemma, an insertion/induction argument gives
   `χ ≤ 2` for a connected map.
3. **Genus-zero realization.** That a connected genus-zero rotation system is
   realized by an actual plane/sphere drawing (which would make the `PlaneData`
   interfaces of 51/53/54 concrete) remains topology, cited not proved.

Script 56 therefore delivers the permutation foundation (V/E/F as orbit counts,
`2E = #darts`, and the universal evenness / integer-genus result) plus the two
genus-zero seeds; the swap split/join lemma, connectedness, and realization are
the explicitly remaining layer.

## 6. API grounding (Lean 4.34.0-rc2)

* Orbits: `Equiv.Perm.cycleType`, `sum_cycleType`, `sum_cycleType_le`,
  `cycleType_one`, `card_fixedPoints` relationship; there is **no**
  `numCycles`.
* Cycles of a swap: `isCycle_swap`, `support_swap`, `IsCycle.cycleType`.
* Signs: `sign_of_cycleType`, `sign_mul`, `sign_inv`; parity bookkeeping done
  with a private `(-1)^n` mod-2 iff lemma over `ℤˣ`.
* Involutions: `dvd_of_mem_cycleType`, `two_le_of_mem_cycleType`,
  `orderOf_dvd_of_pow_eq_one`.
* Multiset induction here requires the motive form
  `induction m using Multiset.induction_on with | empty => … | cons a m ih => …`
  where the inductive hypothesis `ih` is itself a function of the restricted
  premise.
