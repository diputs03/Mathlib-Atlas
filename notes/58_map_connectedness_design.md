## Purpose

Script 56 proved that the Euler characteristic `χ = V − E + F` of *every* combinatorial
map is even and that an integer genus exists (`χ = 2 − 2g`); script 57 supplied the
transposition split/join orbit lemma (`±1`). The remaining hypothesis standing between
the parity result and the topological bound `χ ≤ 2` (equivalently `g ≥ 0`) is
**connectedness**: the darts belonging to one surface component must be linked, purely
combinatorially, by walking across edges and around vertices. This file defines that
notion and proves the structural facts an edge-insertion / spanning-tree argument for
`χ ≤ 2` will need.

## Model (restated standalone, as digit-prefixed scripts cannot import each other)

A `Map α` is a finite type `α` of darts with:

- `edge : Perm α`, a fixed-point-free involution (`edge² = 1`, `edge x ≠ x`) — the edge
  involution `τ`;
- `vert : Perm α` — the vertex rotation `σ`;
- `face := edge * vert⁻¹` — the face permutation `φ = τσ⁻¹`.

## What is proved

1. **Primal–dual group identity — `faceGroup_eq_vertGroup`.**
   `vertGroup := closure {τ, σ}` and `faceGroup := closure {τ, φ}` are equal as
   subgroups of `Perm α`.
   - `φ = τσ⁻¹ ∈ closure {τ, σ}` (product of a generator and an inverse of a generator);
   - `σ = φ⁻¹τ` (using `τ² = 1`, proved in `vert_eq_face_inv_mul_edge`), so
     `σ ∈ closure {τ, φ}`.
   Each inclusion uses `Subgroup.closure_le` (the `closure s ≤ H ↔ s ⊆ H` iff).
   Consequence: a map is connected iff its dual (vertices and faces interchanged) is
   connected — exactly the symmetry Euler's formula exhibits between V and F.

2. **Explicit walk characterization — `Reachable` and `connected_iff_reachable`.**
   `Reachable M x y` is an inductive relation generated by single `τ`/`σ` steps in
   either direction (`edgeStep`, `edgeInvStep`, `vertStep`, `vertInvStep`), reflexivity
   and transitivity; `Reachable.symm` reverses a walk. We prove, in both directions,
   ```
   y ∈ orbit (closure {τ,σ}) x  ↔  Reachable M x y.
   ```
   - `orbit ⊆ Reachable` (`orbit_subset_reachable`): the set of permutations that move
     every reachable dart to a reachable dart **in both directions** is shown to be a
     subgroup containing `τ` and `σ` (the two-direction conjunct is what makes the set
     closed under inversion); hence it contains the closure.
   - `Reachable ⊆ orbit` (`reachable_subset_orbit`): induction on the walk. Each
     generator step is witnessed by the corresponding subgroup element (the inverse
     edge step uses `τ² = 1`; the inverse vertex step by `σ⁻¹(σ y) = y`), and
     transitivity composes witnesses via subgroup multiplication (`smul_smul`).
   `Connected := ∀ x, orbit vertGroup x = Set.univ` is therefore equivalent to
   `∀ x y, Reachable M x y` (`connected_iff_reachable`), and it suffices to check
   transitivity out of a single base dart (`connected_iff_base`).

3. **The genus-zero seeds are connected.**
   The one-edge link (`edge = swap 0 1`, `vert = 1`) and loop (`edge = vert = swap 0 1`)
   on `Fin 2` from script 56 both satisfy `Connected`
   (`linkMap_connected`, `loopMap_connected`), proved by `fin_cases` and the
   `Reachable` constructors (`by decide` for the off-diagonal `swap` steps).

## What is deliberately NOT proved here

- **`χ ≤ 2` / `genus ≥ 0` for connected maps** is script 59. It consumes this
  connectedness characterization together with a *general* transposition `±1` lemma:
  multiplying a permutation by a transposition either splits one cycle into two
  (`orbits + 1`) or joins two cycles into one (`orbits − 1`). Script 57 proved the
  adjacent-same-cycle split and the fixed-point join; 59 needs the general
  two-distinct-nontrivial-cycle join (and, for a clean induction, the non-adjacent
  same-cycle cut). A spanning-tree / edge-insertion argument then walks the connected
  `Reachable` graph while tracking `χ` with the `±1` lemma, starting from a genus-zero
  seed.
- **Genus-zero topological realization** — that a connected map with `χ = 2` is actually
  realizable as a cell decomposition of the sphere (and that `χ = 2 − 2g` computes the
  genus of an orientable surface) — is genuine topology, not permutation combinatorics.
  It remains the frontier's terminal layer gap and should be cited/proved as topology
  rather than asserted from the dart model.

## Technical notes specific to Lean 4.34.0-rc2

- An inductive declared where a section `variable (M : Map α)` is in scope silently
  captures that variable; declaring `Reachable` with its own implicit type parameter
  `{β}` and explicit `(M : Map β)`, outside the `Map` namespace's `variable (M)`, keeps
  the constructor signatures clean (the map is a parameter and is implicit in the
  constructors).
- `Subgroup.closure_le` is an iff `closure s ≤ H ↔ s ⊆ H`; the subgroup argument is
  explicit. Building an explicit carrier `Subgroup` and applying `closure_le` is more
  robust here than invoking the generated `closure_induction`.
- Membership `y ∈ MulAction.orbit H x` is the two-field existential
  `∃ (g : H), g • x = y` (the witness already carries membership). Subgroup-action
  calculations compose with `smul_smul` and cancel with `inv_smul_smul`; the
  existential's `•`-equation is definitionally the underlying `Perm` application but is
  not syntactically identical, so it is normalized with `have h' := h` / `simpa`.
- `set_option linter.unusedSectionVars false` silences the benign warning that the
  group-only lemmas do not use `Fintype`/`DecidableEq`; no other warning is suppressed.
